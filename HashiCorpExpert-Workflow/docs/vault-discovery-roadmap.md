# Vault Discovery Agent Roadmap

## Phase 1: Discovery Pack

- Primary Vault Discovery Agent.
- Modular Copilot skills.
- Standard Markdown and JSON outputs.
- Redaction and evidence rules.
- Example reports and schema.

## Phase 2: Deterministic Helpers

- Add optional scripts for local metadata scans.
- Add schema validation.
- Add report linting.
- Add repository inventory summarization.
- Add CI-compatible read-only report generation.

## Phase 3: Portfolio Aggregation

- Collect JSON reports centrally.
- Build dashboard ingestion model.
- Add migration wave planning views.
- Add risk trend reporting.

## Phase 4: Planning Agents

- Add Vault policy planning.
- Add platform integration planning.
- Add CI/CD auth planning.
- Add test strategy generation.

## Phase 5: Approved Remediation Agents

- Add code remediation only after explicit approval.
- Add manifest remediation.
- Add CI/CD remediation.
- Add Vault policy and auth method generation.
- Add rollback and validation automation.
