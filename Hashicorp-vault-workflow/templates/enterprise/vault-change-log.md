## Change Control Rules

- Before release freeze, changes may be made in `vault/`.
- After release freeze, changes require a new version and change reason.
- Do not edit frozen baselines in place.
- Any change affecting auth, policy, secret paths, rotation, or rollback requires security/operations review.

**Why?** Vault changes need a traceable security and operations history.
